本扩展需要配套的服务端插件才能工作：打开本扩展所在文件夹，双击 install.bat（Linux/mac 用 sh install.sh），然后重启 SillyTavern。

只需一步：在 GitHub 或 Gitee 生成一个私人访问令牌（Token）并粘贴到下面，插件会自动创建私有仓库、完成全部配置，并立即执行第一次备份。

如何获取令牌？（点击展开教程）
GitHub（推荐 fine-grained token）：
  1. 打开 GitHub Token 创建页（也可从头像 → Settings → Developer settings 进入）
  2. 名字随意，Expiration 选择期建议 1 年以上
  3. Repository access 选 All repositories（或只选你要存放备份的仓库）
  4. Permissions：Repository permissions 里把 Contents 设为 Read and write；若想让插件自动建仓，还需 Administration 设为 Read and write
  5. 生成后复制 github_pat_ 开头的完整 token
classic token（创建入口）只需勾选 repo 一项。
Gitee（国内网络推荐）：
  1. 打开 Gitee 私人令牌创建页（也可从头像 → 设置 → 安全设置 → 私人令牌进入）
  2. 勾选 projects 权限
  3. 提交后复制显示的令牌（只显示一次）
