Git Backup & Restore
服务端插件未安装

本扩展需要配套的服务端插件才能真正执行 git 操作：

  1. 自动（推荐）：打开本扩展所在文件夹（位置二选一： SillyTavern/public/scripts/extensions/third-party/st-git-backup/ 或 SillyTavern/data/default-user/extensions/st-git-backup/）， 双击 install.bat（Linux/mac 用 sh install.sh）—— 脚本会自动复制服务端插件并打开 enableServerPlugins。
  2. 重启 SillyTavern，刷新本页面。

手动做法：把扩展文件夹整体复制为 SillyTavern/plugins/st-git-backup/， 再把 config.yaml 的 enableServerPlugins 改成 true，重启。
